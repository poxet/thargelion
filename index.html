Thargelion

The logic behind complex business

We build the backend systems that run complex businesses

Thargelion is a software consultancy that takes on the hard parts: the business logic and backend systems large companies depend on, across many different domains. When the rules get complicated, we build software that keeps them straight.

We build websites too, plus our own products and a suite of open-source .NET components. Across every domain the aim is the same: dependable software doing the demanding work behind the scenes.
